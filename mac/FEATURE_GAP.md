## 0. 结论速览

原生版已完成五大分区、窗口层级、穿透、多显示器、快捷键、备份、8 向缩放、对齐等核心能力，
`feature parity` 已基本达成。但对照 README，仍有 **10 项功能级缺口** 与 **5 组体验级差异**。
其中 3 项（面包屑导航、文件重命名、收集箱网格/排序）直接影响分区核心体验，建议退役前补齐。

## 1. 缺失功能（README 有描述，mac 版尚未实现）

### 1.1 Portal 面包屑导航（Breadcrumb Trail）
- **README 依据**（§4.1）：子文件夹深度穿梭浏览时，「顶部自动浮现多级路径面包屑导航
  （`根目录 > 子文件夹A > 子文件夹B`），支持祖先节点一键返回或退出子文件夹浏览」。
- **mac 现状**：`PortalView` 只有单一「返回上一级 / 返回根」按钮（`history` 栈 + `chevron.left` / `house` 图标）。
- **缺口**：无多级路径条 UI，无法点击中间祖先节点直接跳转。
- **建议**：工具栏下方加一行面包屑（`ScrollView(.horizontal)` + `Button` 链），
  点击段 → `currentPath = 段路径`，`load()` 刷新，`history` 截断到该段。

### 1.2 文件/文件夹行内重命名 + 系统级重名递增
- **README 依据**（§4.1）：「支持直接在分区网格/列表中进行行内编辑重命名，支持系统级重名自动递增」。
- **mac 现状**：`createFolderInPortal` 已实现重名递增（`新建文件夹`、`新建文件夹 2`），
  但文件/文件夹**重命名入口缺失**（文件右键菜单只有 打开/访达显示/废纸篓）。
- **建议**：文件右键菜单加「重命名」，`alert` 输入 → `FileManager.moveItem` 改名，
  复用现有重名递增逻辑。

### 1.3 Portal 工具栏「外部访达定位」「即时刷新」快捷动作
- **README 依据**（§4.1）：面包屑导航「附带右侧『外部访达定位』与『即时刷新』快捷动作」。
- **mac 现状**：工具栏无「定位当前目录到访达」「手动刷新」按钮（仅文件右键有单文件「在访达中显示」；
  smart 有刷新按钮，普通 portal 靠文件夹监听自动刷新）。
- **建议**：工具栏补 `NSWorkspace.shared.open(currentPath)` 定位按钮 + 手动 `load()` 刷新按钮。

### 1.4 收集箱网格/列表切换 + 多维排序
- **README 依据**（§4.5）：「支持网格（Grid）与紧凑列表（List）一键切换；支持按名称、修改时间、
  文件大小及扩展名多维排序」。
- **mac 现状**：`CollectionView` 仅 `listView`，无 `viewMode` 切换、无排序。
- **建议**：`CollectionView` 复用 `PortalView` 的 grid/list 双布局 + 排序工具栏
  （收集箱条目含 `size`/`modDate` 元数据，需在 `addFilesToCollection` 时补录）。

### 1.5 顶栏「悬浮胶囊 ↔ 贴顶吸附」双形态 + 图钉语义
- **README 依据**（§交互1）：顶栏支持「悬浮药丸模式」与「贴顶吸附固定模式」自由切换，
  图钉语义（`Pin` 已固定 / `PinOff` 未固定）。
- **mac 现状**：`TopBarPanel` 固定贴顶居中（`screen.frame.height - h - 12`），无悬浮模式、无切换按钮。
- **备注**：Electron 实际代码（`TopBar.tsx` / `main.ts` 托盘）也未完整落地此功能，README 属文档超前。
  可作「低优先级 / 可跳过」处理。

### 1.6 顶栏三个对齐模式按钮
- **README 依据**（§交互1、TopBar.tsx）：顶栏含「顶部横向排序 / 左侧纵向对齐 / 右侧纵向对齐」三段控制 + 重新对齐。
- **mac 现状**：`TopBarView` 只有「重新对齐」一个按钮（`rectangle.3.offgrid`），
  三种对齐模式仅存在于托盘子菜单与画布右键菜单。
- **建议**：顶栏加三态对齐分段控件（复用 `align(mode:)`）。

### 1.7 托盘菜单「品牌标牌」与「吸附到屏幕顶端」
- **README 依据**（§交互2）：托盘菜单顺序第 1 项「DeskIsle 桌岛（品牌标牌）」、
  第 6 项「吸附到屏幕顶端（顶端吸附切换）」。
- **mac 现状**：`setupStatusItem` 首项是「显示/隐藏分区」，无品牌标牌、无吸附项。
- **建议**：首项加 `NSMenuItem`（`isEnabled = false`）作品牌标牌；吸附项随 1.5 一并决定是否保留。

### 1.8 双击底边/右下角手柄 → 自适应高度
- **README 依据**（§交互7、§快捷键）：「双击分区底边/右下角手柄：一键自适应内容最佳高度」。
- **mac 现状**：`ResizeGrip` 仅 `DragGesture` 缩放，无 `onTapGesture(count: 2)`。
- **建议**：底边（`.b`）与右下角（`.br`）手柄加双击手势 → `autoFitHeight(id)`。

### 1.9 8 向缩放的原生拉伸光标切换（NSCursor）
- **README 依据**（§交互6）：「光标划向边缘手柄瞬间点亮并无缝切换为系统对应拉伸光标
  （`ew-resize`、`ns-resize`、`nwse-resize`、`nesw-resize`）」。
- **mac 现状**：`ResizeGrip` 未设置 `NSCursor`，悬停时光标不切换。
- **建议**：`ResizeGrip` 加 `onHover` → 按 grip 方向 `NSCursor.push/pop`
  （`NSCursor.resizeLeftRight` / `resizeUpDown` / 对角用自定义 cursor）。

### 1.10 排序刷新的「空间二维分层 + tie-breaker」幂等算法
- **README 依据**（§交互4）：「引入空间行列阈值分层判定（`|Δy|>50px` 或 `|Δx|>50px`）与原始索引
  决定性仲裁，无论连续点击多少次『排序刷新』，分区位置绝对 100% 幂等恒定」。
- **mac 现状**：`align(mode:)` / `realign()` 为简化的一维逐行重算（结果确定，但未复刻
  阈值分层 + tie-breaker 逻辑）；新建分区用 `findFreeSlot` 光栅扫描，未按 `lastAlignMode` 计算槽位。
- **备注**：mac 版 realign 每次完全重算、天然幂等，实际观感差异小，属「可简化保留」。

## 2. 可调整 / 可补回的功能（mac 有意简化，配置字段仍保留）

> `Config.styleKeys` 仍保留 `bgColor / bgOpacity / blurAmount / borderRadius / textColor` 可读写，
> 仅 UI 入口被移除，随时可补回。

| 项目 | Electron 版 | mac 版现状 | 调整方向 |
|---|---|---|---|
| 分区背景色预设 | 7 种暗色（`#0f172a` 等） | 移除，仅标题高亮色 | 可补 `bgColor` 色板 |
| 背景不透明度 | `bgOpacity` 滑块 0.1–0.95 | 移除 | 可补滑块 |
| 毛玻璃模糊度 | `blurAmount` 滑块 0–40px | 固定 `.ultraThinMaterial` | 可补滑块（需映射系统 material） |
| 圆角半径 | `borderRadius` 滑块 4–28px | 固定 16pt（`Look.cornerRadius`） | 可补滑块 |
| 宽高/默认/最小宽度 | slider + 预设芯片（280/320/380/460 等） | Stepper 数值 | 可补预设芯片 |
| 全局设置「一键重置全部宽度」 | 有按钮 | 移到托盘菜单 | 可回填全局设置 |
| 全局设置「显示器信息」区块 | 有 | 删除 | 可补 |
| 便签折角设计 | 有折角便签纸 | 普通 `TextEditor` | 视觉可选 |
| 待办划线动效 | 优雅划线动画 | 静态 `strikethrough` | 视觉可选 |
| 滚动条智能消隐 | `height>=autoFitHeight` 时隐藏 | `ScrollView` 常显 | 视觉可选 |
| hover 预览层级提权 | `z-40` | 单窗口模型，仅改高度 | 影响小，可跳过 |

## 3. mac 版额外增强（超出 README）

- 「拦截壁纸点击」护盾窗口（`kCGDesktopIconWindowLevel`）。
- 每分区独立锁定 `isLocked`（README 仅有全局锁定）。
- **网格平铺（grid）对齐模式**（Electron 托盘菜单无此项，仅画布右键有）。
- 分区设置内「折叠 / 锁定」toggle。
- 托盘菜单多出「导出/导入配置备份」「所有分区自适应高度」「全部还原默认宽度」。
